# Audio Files Directory

This directory hosts the MP3 files referenced by the interactive turntable portfolio.
The soundtrack assignments defined in `PORTFOLIO.md` and `src/data/tracks.ts` are:

1. **`want-u.mp3`** — *Want U* by Clara La San (Section 01: About Me)
2. **`the-less-i-know-the-better.mp3`** — *The Less I Know the Better* by Tame Impala (Section 02: Skills)
3. **`midnight-city.mp3`** — *Midnight City* by M83 (Section 03: Selected Works)
4. **`times-like-these.mp3`** — *Times Like These* by EDEN (Section 04: Experiments)
5. **`nothing-can-change-this-love.mp3`** — *Nothing Can Change This Love* by Sam Cooke (Section 05: Contact)

Place your licensed audio files into this folder with these exact names.
If any file is absent, the player will gracefully display a non-disruptive notification without crashing or blocking interface interactions.
